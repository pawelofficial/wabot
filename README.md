# wabot
whatsapp bot

i want to create an app that will serve users a whatsapp profile to talk ( a whatsapp bot).
- the bot will be an ai ( claude )
- the bot will serve a purpose of being an assistant to a personal trainer and will ease the trainer with managing their trainees
- currently the features i wish to support for the bot are:
    - tracking users submissions of their weight measurements
    - tracking users submissions of how they are sticking to the training plan 
    - tracking users submission of how they arre sticking to their diet 
    - the bot will be able to have some limited conversation with the user regarding their arrangement with the trainer, like if the user asks what is my training plan the bot should answer that 
    - bot will be able to message the user asking for the quick report of how they are doing 
- the submissions by clients will go to the database - hosted on gcp service
- the trainer will have a dashboard with users data
